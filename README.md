# Climb.AI — AI-Powered Bouldering Beta Solver

An end-to-end AI system that analyzes indoor boulder problems from photos and generates personalized climbing beta (movement sequences) using Claude Vision AI.

## Features

- **Computer Vision Pipeline** — Upload 1–10 photos of a boulder problem; Claude Vision AI detects 24 hold types with normalized coordinates, confidence scores, surface normals, and friction coefficients
- **Route Graph** — Weighted directed graph of reachable hold transitions, built from biomechanical constraints per climber profile
- **Biomechanics Engine** — 33 move types validated against 30+ climber anthropometric fields (height, ape index, shoulder mobility, finger strength, hip flexibility, injuries)
- **Physics Simulation** — Coulomb friction, deadpoint/dyno momentum equations, center-of-mass balance, barn-door risk
- **8 Beta Types** — High percentage, energy efficient, static, dynamic, heel-hook focused, toe-hook focused, compression, and coordination sequences generated by Claude
- **Difficulty Analysis** — V-grade and Fontainebleau estimation, intensity breakdown (power, finger, core, coordination, balance, mobility)
- **Interactive Canvas** — Zoomable wall view with color-coded holds, active limb positions, CoM indicator, click-to-inspect
- **Climber Profile** — Persistent profile with all anthropometric and strength/mobility fields; affects which moves are generated

## Quick Start

### Prerequisites

- Docker and Docker Compose
- Anthropic API key

### Run with Docker

```bash
git clone https://github.com/aprameyak/climb.git
cd climb
echo "ANTHROPIC_API_KEY=your_key_here" > .env
docker-compose up --build
```

Open http://localhost:3000

### Local Development

**Backend:**
```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # add your ANTHROPIC_API_KEY
uvicorn main:app --reload --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev
```

Open http://localhost:3000

## Hold Types Recognized

Crimp, Sloper, Jug, Pinch, Pocket (mono/2-finger/3-finger), Edge, Volume, Undercling, Sidepull, Gaston, Crack, Horn, Compression, Mantle, Toe Hook, Heel Hook, Knee Bar, Foot Chip, Slab Foot, Campus Rung, Wooden Rung, Polyurethane Jug, Training Hold

## Beta Types Generated

| Beta Type | Description |
|-----------|-------------|
| `HIGH_PERCENTAGE` | Highest probability of success; conservative, reliable moves |
| `ENERGY_EFFICIENT` | Minimizes energy expenditure; emphasizes rests and momentum |
| `STATIC` | All moves controlled, no dynamic motion; feet always placed before hands |
| `DYNAMIC` | Momentum-based; deadpoints and dynos to skip holds |
| `HEEL_HOOK` | Maximizes use of heel hooks for lower-body engagement |
| `TOE_HOOK` | Maximizes use of toe hooks for body tension |
| `COMPRESSION` | Body tension between opposing holds; squeeze technique |
| `COORDINATION` | Simultaneous limb movement; cross-through, Egyptian, flag sequences |

## Move Types (33 total)

Standard step, high step, drop knee, flag (inside/outside), Egyptian, cross-through (front/back), rock-over, mantle, toe hook, heel hook, knee bar, bicycle, twist lock, side pull, gaston, undercling, compression, stemming, bridging, campus (1-2-3/1-3-5/1-4-5), dyno (single-hand/double-hand), deadpoint, bump, match, stationary rest, knee scum, bat hang

## Climber Profile Fields

Height, wingspan, ape index (computed), weight, arm length, shoulder width, hip width, leg length, foot size, shoulder mobility, hip flexibility, hamstring flexibility, ankle flexibility, wrist flexibility, finger strength (1–5 fingers), crimp/sloper/pinch preference, pull strength, core strength, leg strength, explosive power, endurance, fear of heights, fear of falling, experience grade, preferred style, injuries (multi-select), flash grade, project grade, max comfortable reach (computed)

## Technical Notes

- **Vision accuracy**: Claude Vision AI provides strong conceptual hold detection but coordinates can drift ±5% on complex images. Using 3+ photos from different angles significantly improves confidence.
- **Grade estimation**: Based on hold type difficulty distribution + wall angle modifier. Accuracy is ±1–2 V-grades vs. setter intent. The system does not read tape/colour markers.
- **Beta generation**: Claude acts as an elite climbing coach interpreting the hold map. Move sequences are physically validated by the biomechanics engine post-generation.
- **No database**: All data persists as JSON files in `backend/data/`. The `climb_data` Docker volume provides durability.
- **Custom models**: Replacing Claude Vision calls in `hold_detector.py` with a fine-tuned YOLO/SAM model for hold segmentation would improve coordinate precision. The interface is `List[DetectedHold]` — drop-in replaceable.
